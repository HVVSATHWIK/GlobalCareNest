## 2024-05-24 - Dynamic ARIA Labels on Toggle Buttons\n**Learning:** When a button toggles state (like a theme toggle), the `aria-label` should dynamically reflect the *action* that will occur when clicked (e.g., 'Switch to dark mode' vs 'Switch to light mode'), rather than a static description of the button itself. This provides clearer context to screen reader users.\n**Action:** For all future toggle buttons, ensure the `aria-label` or `title` is dynamic and descriptive of the resultant action.
